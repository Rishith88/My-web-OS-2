# My First Web OS

This is my first web OS project. I made a simple operating system look inside a browser using only HTML, CSS and JavaScript.

The idea was to make a desktop screen with wallpaper, icons, windows and a taskbar, just like a real OS but very basic and also it has a windows kind of bottom bar with time also visible which in my opinion is a good feature.

## What it has

Home screen / Desktop:
- It is a desktop screen with Avenger Image.webp wallpaper background.
- It shows a Welcome message that fades out after 5 sec
- It shows a Live clock and date on the right side (IST time)
- It shows a Session timer on top navbar that counts from 00:00:00
- It shows 6 desktop icons - Calculator, Stopwatch, Calendar, Notepad, To-Do list,CountDown timer
- It shows a Taskbar at the bottom that shows which apps are open

Windows system:
- Click an icon to open the app in a window
- You can drag windows around by the titlebar
- Minimize, Maximize and Close buttons work
- Click taskbar icon to minimize / bring back
- Opened app shows "Open" badge on desktop icon

### 1. Calculator
It is a simple calculator app. This can do + - * / , AC to clear, Del to delete one digit, . for decimal. Made with a form and buttons.

### 2. Stopwatch
It is a simple stopwatch app. Start button, Stop and Reset buttons with images. Shows HH:MM:SS. counts every second.

### 3. Calendar
It is a mini calendar that shows todays date, day, month and year automatically. It updates every minute.

### 4. Notepad
It is a simple notepad app. This can write text and save it.

### 5. To-Do list
It is a simple to-do list app. This can add tasks, mark them as done, delete them.

### 6. CountDown timer
So the thing is it is a Simple countdown timer. It can set a time and it counts down to 00:00:00.


## Files in this project

- `index.html` - So his thing conatins the main desktop, windows logic, taskbar, clock
- `calculater.html` - calculator app 
- `stopwatch.html` - stopwatch app
- `calendar.html` - calendar app
- `notepad.html` - notepad app
- `todolist.html` - to-do list app
- `countdown.html` - countdown timer app
- `*.png`, `*.webp` - icons and wallpapers (calculater.png, stopwatch.png, calendar.png, background.png, start.png, stop.png, reset.png, Avenger Image.webp)    

No frameworks or libraries used. Just plain JS.

## How to run

No need to install anything.

1. Download / clone this repo
2. Just double click on `index.html` to open in browser
3. Or if using VS Code, right click index.html -> Open with Live Server

Thats it.

## How to use

- Click Calculator icon to open calculator, type numbers and press = 
- Click Stopwatch icon, press start button image to start
- Click Calendar icon to see todays date
- Click Notepad icon to open notepad, type text and save it
- Click To-Do list icon to open to-do list, add tasks, mark them as done, delete them
- Click CountDown timer icon to set a time and it counts down to 00:00:00
- Drag window from top blue/black bar to move it
- Use - button to minimize, square button to maximize, X to close
